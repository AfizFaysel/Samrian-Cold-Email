# Bundled fonts

These Latin subsets ship with the app so a build never depends on Google Fonts. All are licensed
under the SIL Open Font License 1.1 (<https://openfontlicense.org>), and each file carries its
copyright notice and a link to that license in its own metadata.

| File                     | Font       | Copyright                   |
| ------------------------ | ---------- | --------------------------- |
| `figtree-latin.woff2`    | Figtree    | The Figtree Project Authors |
| `geist-mono-latin.woff2` | Geist Mono | The Geist Project Authors   |

Figtree is the interface font, matching the Astryx neutral theme. It is a variable font (weights
300 to 900), subset to Basic Latin, Latin-1 and common punctuation from the
[google/fonts](https://github.com/google/fonts/tree/main/ofl/figtree) source.
